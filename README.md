# Manipulação da árvore DOM

Exercícios de JavaScript para acessar e modificar elementos de uma página HTML.

## Arquivos

- `index.html`: estrutura da página.
- `script.js`: exemplos de alteração de conteúdo e interação com elementos.

## Como consultar

Abra `index.html` em um navegador e examine `script.js` para acompanhar os exercícios.
